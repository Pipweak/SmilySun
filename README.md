# SmilySun ☀️

**SmilySun** est une application Android météo simple, conçue pour apprendre le développement mobile avec **Kotlin** et **Jetpack Compose** étape par étape.

## 📌 Objectif du projet
L'objectif principal est pédagogique. La **V1** se concentre sur les bases du développement Android natif en utilisant uniquement des données locales et fictives, évitant ainsi la complexité des APIs et du réseau pour privilégier la compréhension de l'UI et de l'état.

## 🚀 Stack Technique
- **Langage :** [Kotlin](https://kotlinlang.org/)
- **UI :** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Outil :** [Android Studio](https://developer.android.com/studio)
- **Données :** Locales / Fictives (V1)

## 🛠️ Installation & Lancement
1. Clonez le dépôt.
2. Ouvrez le projet dans **Android Studio**.
3. Attendez la fin de la synchronisation Gradle.
4. Lancez l'application sur un émulateur ou un appareil physique.
