## 🏗️ Structure recommandée du code
Le plan prévoit une organisation modulaire au fur et à mesure de la progression :
- `model/` : Classes de données (ex: `WeatherDay`).
- `data/` : Sources de données (ex: `FakeWeatherRepository`).
- `ui/` : Composants Jetpack Compose.
- `theme/` : Thème de l'application.
